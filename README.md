# CS250

How do I interpret user needs and implement them into a program? How does creating “user stories” help with this?

Interpreting user needs means understanding what users want to achieve and turning those goals into clear technical tasks. Creating user stories helps with this as it presents itself in the format of "As a [user], I want [goal], so that [reason]". This helps bring clarity to what the user needs are and the reason behind it. 


How do I approach developing programs? What Agile processes do I hope to incorporate into my future development work?

When developing programs, I start by understanding the problem, identifying user needs, and breaking the project into manageable parts. In my future work, I hope to incorporate agile practices such as iterative development and user stories to stay user-focused and deliver a quality product. 

What does it mean to be a good team member in software development?

Being a good team member in software development means collaborating effectively, communicating clearly, and contributing to shared goals.
